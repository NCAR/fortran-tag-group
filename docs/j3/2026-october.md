# J3 Meetings
## 2026, October 20,22,26,28
[Meeting documents](https://j3-fortran.org/doc/meeting/241)
### Updates
- [Flang Report](https://j3-fortran.org/doc/year/26/26-212r2.txt)
  - Flang is an LLVM open-source compiler for Fortran
  - Bug fixes, better performance, progress in OpenMP GPU offloading and other
    parallel features
- [Fortran Lang and LFortran Report](https://j3-fortran.org/doc/year/26/26-213.txt)
  - [Fortran Package Manager](https://fpm.fortran-lang.org/) (fpm) has
    received a lot of new packages
  - addition metapackages (aka dependencies) BLAS, HDF5, NetCDF, MPI have
    been added
  - [lfortran](https://lfortran.org/) a modern interactive LLVM-based Fortran compiler
- Work has been mainly cleaning up the Fortran 2028 draft standard
